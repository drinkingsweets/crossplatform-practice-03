# Практическая работа 3 — Electron

Кросс-платформенная разработка. Практикум работы с фреймворком Electron.

Власенко Марк Евгеньевич, ТРПО23-3. Вариант 8. 13 октября 2026 года.

## Запуск

Требуется Node.js 24 LTS и npm 11 или новее.

```sh
npm ci
npm start
npm test
npm run dist
```

Кнопка читает текущий рабочий каталог при запуске из исходников. В упакованном приложении выводится включённый в дистрибутив каталог примеров `resources/example`. Это даёт воспроизводимый результат независимо от того, как Finder запустил приложение.

Строка состояния показывает настоящие версии Electron, Chromium и Node.js процесса приложения. Установленный в системе Node.js используется для npm и может отличаться от встроенного в Electron.

## Архитектура

- `main.js` — окно, жизненный цикл, проверка отправителя IPC и системные операции.
- `directory.js` — чтение разрешённого каталога и обработка ошибок.
- `preload.js` — только два разрешённых метода API.
- `renderer.js` — интерфейс, отображение имён через textContent.
- `index.html`, `styles.css` — локальный интерфейс с CSP.
- `tests/` — проверки чтения каталогов и границ доступа.
- `evidence/`, `report/` — результаты проверки и отчёт.

Использованы contextIsolation=true, nodeIntegration=false и sandbox=true. Новые окна, внешняя навигация и разрешения браузера отключены. Произвольные пути через IPC не принимаются.

Сборка предназначена для учебной проверки, без сертификата Developer ID и нотариального заверения. Windows/Linux конфигурации предусмотрены, но проверка выполняется на macOS ARM64.
